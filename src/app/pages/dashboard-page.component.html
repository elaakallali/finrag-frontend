Workspace

Separate spaces for users and admins

Users work with financial reports and search results, while admins upload and track regulatory references in a dedicated area.

User Upload a report and ask business questions
Admin Index regulation documents and monitor ingestion
Goal Keep the two journeys clearly separated
01

User report upload

Send a financial report to the report store so it can be searched afterward.

 02

User search

Search the indexed report content and inspect the retrieved sources and similarity scores.

 03

Admin regulation ingestion

Upload a regulatory reference document and add it to the regulation knowledge base.

 04

Admin regulation history

Review previously indexed regulation documents with their chunk count and ingestion mode.
